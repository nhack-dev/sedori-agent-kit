# せどり AI エージェント キット

あなたの AI エージェント（Claude Code など）にこのフォルダを読ませると、国内せどり（新品の転売）の毎日の作業を手順どおりに続けられるようにするための、手順書と小さな道具のセットです。

- 仕入れ候補を探す（売れているか・相乗りできるか・危ない商品でないか）
- 1件ごとの利益を出す（販売手数料・送料・梱包・為替・返品の見込み）
- 出品文の下書きを作る
- 出品中の商品の在庫と値段を見直す（赤字・品切れの前に止める）
- 規約と法律の注意（API の利用条件・出品できない物・許可が要る物）

最終的に「買う」「出品する」「値段を変える」を決めるのは、あなた（オーナー）です。道具は案と数字を出し、エージェントは決まりの範囲で手を動かします。

## 費用について

このキットそのものに費用はかかりません。動かすときにかかるのは、あなたが自分で契約するものだけです。

- あなたの AI エージェントの利用料
- あなたが取る API キーの利用料（無料のものもあります。下の表）
- 仕入れの代金・送料・各モールの手数料

こちらのサーバーや鍵は一切使いません。鍵はあなたのパソコンの `.env` にだけ置きます。

## 最初の10分

1. Python 3.11 以上が入っているか確かめます。

   ```
   python3 --version
   ```

2. 道具が動くか、ネットにつながずに確かめます（鍵は要りません）。

   ```
   bash scripts/selftest.sh
   ```

   最後に「落ちた道具 0本」と出れば準備できています。

3. 見本のデータで1周やってみます。

   ```
   python3 scripts/hantei.py samples/candidates.csv
   python3 scripts/rieki.py --sell 4980 --cost 2800 --fee-rate 0.15 --ship 600
   python3 scripts/minaoshi.py samples/listings.csv
   ```

4. AI エージェントに「AGENT.md を読んで、今日の作業を始めて」と頼みます。Claude Code なら、このフォルダで起動するだけで `CLAUDE.md` から `AGENT.md` を読みます。

5. 本番で使うときは `.env.example` を `.env` に写し、取ったキーを入れます。`config/settings.example.json` を `config/settings.json` に写し、自分の数字（送料・梱包・目標の利益率）に直します。

## 必要なキーと取り方

全部そろえなくても始められます。ないものは手で調べる手順（playbooks）に切り替わります。

| キー | 何に使うか | 取り方 | 費用 |
|---|---|---|---|
| Amazon SP-API（出品者用） | 手数料の見積り・出品価格・出品の更新・出品制限の確認 | セラーセントラルで開発者登録をして、自分のアカウント専用のアプリを作り、LWA の client id / secret と refresh token を発行 | API 自体の利用料は公式で確かめてください。出品用アカウントの月額は別 |
| 楽天ウェブサービス | 仕入れ先候補の値段を調べる（商品検索） | webservice.rakuten.co.jp で「アプリ ID」と「アクセスキー」を発行（両方が必須） | 無料。クレジット表示が必要 |
| Yahoo!デベロッパー | 仕入れ先候補の値段を調べる（JAN 検索も可） | developer.yahoo.co.jp で Client ID を発行 | 無料。1秒1回まで・クレジット表示が必要 |
| Keepa（任意） | 値段・ランキング・出品者数の履歴 | keepa.com で API を契約 | 有料（トークン制） |

各 API の手順と条件は `playbooks/05-kiyaku.md` にまとめました。公式ページの URL も書いてあります。

## できないこと（正直に）

- **仕入れの自動購入はしません。** 楽天・Yahoo! の商品検索 API は「探す」ためのもので、買う操作はできません。買うのはあなたが画面で行います。
- **Amazon・楽天・メルカリ等の画面を機械で読み取る（スクレイピング）ことはしません。** どのサービスも規約で制限しています。公式 API だけを使います。
- **Keepa の利用条件と料金は、このキットを作った時点では公式ページを機械で読めず未確認です。** 契約前に keepa.com で必ず確かめてください。道具は Keepa なしでも動きます。
- **SP-API の登録手順・料金・審査は変わることがあります。** 道具が使う操作の名前（手数料見積り getMyFeesEstimateForASIN など）は Amazon 公式の API 定義で確かめましたが、登録の画面の手順は公式ドキュメントで確かめてから進めてください。
- **楽天の API 規約には「特定の人しかアクセスできない環境での利用」を禁じる条文があります（第10条(10)）。** 自分だけが使う道具が当たるかどうかは、使う前に規約を読み、分からなければ楽天に問い合わせてください。
- **利益の数字は見込みです。** 実際の手数料・送料はあとで明細と突き合わせてください（`playbooks/04-minaoshi.md`）。
- 税金の扱い（消費税・所得の区分）は判断しません。税理士に確かめてください。

## フォルダの中身

```
AGENT.md        エージェントへの指示書（役割・毎日やること・判断の基準・禁止・止まったとき）
CLAUDE.md       Claude Code 向け（AGENT.md を読むように1行）
playbooks/      作業ごとの手順
scripts/        小さな道具（Python 標準ライブラリだけ・既定は試し運転）
templates/      出品文・報告の型
samples/        架空の見本データ
config/         設定の見本（本物は settings.json に写して使う）
```

道具は全部「試し運転」が既定です。外へ送る・書き換える操作は `--go` を付けたときだけ動きます。

## このキットは N-Hack のAIエージェント専用です

このキットは N-Hack の受講生さん専用のプレゼントです。**N-Hack のAIエージェント
（N-Hack のプラグインを入れた Claude Code など）が、このパソコンで動いていること**を
前提にしています。

- どのスクリプトも、最初に `scripts/nhack_gate.py`（門）を通ります。門は、このパソコンに
  N-Hack のAIエージェントの「印」があるかを**読むだけ**で確かめます（ネットにつなぎません・
  何も書き換えません・プラグインには一切触れません）。
- 印が足りない環境では、スクリプトは動かずに止まります（終了コード 2）。この環境でだけ
  動くのが正しい姿です。
- いま N-Hack 環境かどうかは、次のコマンドで確かめられます。

```bash
python3 scripts/nhack_gate.py
```

N-Hack 以外のパソコンにコピーしても動きません。受講生ページ・コンサルチャンネルの案内に
沿ってご利用ください。
