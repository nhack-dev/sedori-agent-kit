# 02 利益を出す

```
python3 scripts/rieki.py --sell 売値 --cost 仕入れ値 [--fee-en 手数料の実額]
```

## 決まり

- **売値は送料込みの実際の売値**（カートの値段＋送料）。新品の最安だけを見ると、送料を足している出品者の分だけ高く見積もってしまいます
- **手数料はその商品の実額**。`sp_api.py fees --asin ... --price ... --go` の合計を `--fee-en` に入れます。大きい・重い物ほど一律の率とずれます
- 実額が取れないときは `settings.json` の `fee_rate_karioki`（初期値 15%）で計算します。**高めに置く**（利益を小さく見る）のが決まりです
- 仕入れ値は**割引を全部引いた後**の額。ただしポイント還元・キャッシュバックは引かない（確実に戻るとは限らない）。戻ったら上振れとして記録する
- 送料・梱包・仕入れ先からの送料・返品の見込みを全部引く。初期値は仮置きなので、自分の契約の実額に直す
- 海外から仕入れるときは `--cost-usd` と `--fx`（その日の為替）を入れる。為替は推測で入れない

## 出てくる数字の読み方

| 表示 | 意味 |
|---|---|
| 利益 | 売値 − 手数料 − 送料と梱包 − 返品の見込み − 仕入れ |
| ROI | 利益 ÷ 仕入れ。目標（初期値 30%）以上で出す |
| 目標を満たす売値の下限 | この値より下げると目標を割る。値下げの下限に使う |
| この売値での仕入れ値の上限 | これより高く仕入れると目標を割る。仕入れのときの上限に使う |

## 毎月の突き合わせ

月に1回、売り場の入金の明細（手数料の実額・返品）と、自分の見込みを比べます。

1. 売れた商品ごとに、見込みの利益と実際の利益を並べる
2. ずれが大きい項目（送料・手数料・返品）を見つける
3. `settings.json` の仮置きの値を実額に近づける案をオーナーへ出す（勝手に変えない）

税金（消費税の還付・所得の区分）は計算に入れていません。税理士に確かめてください。
