# 03 出品文を作る

1. 商品の事実だけを JSON にまとめる（`samples/shouhin.json` の形）
   - 出どころはメーカーの公式ページ・パッケージ。分からないことは書かない
2. 下書きを作る

   ```
   python3 scripts/shuppin_bun.py 自分の商品.json
   ```

3. 「書き直すところ」が出たら直す。0件になるまで出品しない

## 書かないこと

- 根拠を示せない「一番」「最安」「日本一」
- 効き目（治る・効く・痩せる）。化粧品・健康の商品は特に（薬機法・景品表示法）
- 「在庫あり」「即日発送」：売れてから仕入れるなら、実際にできる発送の日数を書く
- 外のページへの誘導・電話番号・連絡先
- 他の出品者・メーカーを悪く言う言葉
- 本物の保証：仕入れの請求書など、出どころを示せる書類があるときだけ（その場合も売り場の決まりに従う）

## 相乗りのとき

既にある商品ページに出品するときは、題名・画像・説明は売り場のカタログのものが使われます。自分で書けるのは「コンディション（状態）の説明」など一部の欄だけ、という売り場が多いです。

- 商品ページの内容（色・入り数・型番）と、自分が仕入れる物が**完全に同じ**か確かめる
- 違うなら、その商品ページには出さない

## 画像

- 自分で撮った画像か、使ってよいと許可を受けた画像だけを使う
- 他の出品者・売り場・メーカーの画像を勝手に写して使わない
