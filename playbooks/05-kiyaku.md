# 05 規約と法律（最初に読む）

ここに書いたのは「気をつける場所」と「確かめる先」です。規約と法律は変わります。**実行の前に、必ず公式の最新を読み、読んだ日付をメモしてください。** 分からないときは止めてオーナーに聞きます。

## 各 API の利用条件

### Amazon SP-API（売り場の操作・手数料・値段）
- 出品者が、自分のアカウントのためだけに使うアプリ（自分で許可するアプリ）を作れます。セラーセントラルで開発者として登録し、アプリを作り、LWA の鍵と refresh token を発行します
- 公式ドキュメント：https://developer-docs.amazon.com/sp-api/
- API の定義（このキットが使う操作の名前の出どころ）：https://github.com/amzn/selling-partner-api-models
  - 手数料見積り getMyFeesEstimateForASIN／出品の値段 getItemOffers（毎秒0.5回）／出品制限 getListingsRestrictions／出品の更新 patchListingsItem（毎秒5回・検証だけの mode=VALIDATION_PREVIEW あり）
- 日本のマーケットプレイス ID・地域の URL は `.env.example` に入れてありますが、公式の一覧でも確かめてください
- 開発者の利用規約・データ保護の決まり（購入者の個人情報の扱いなど）を必ず読む。このキットは購入者の個人情報を扱いません
- このキットを作った時点では、公式ドキュメントのページを機械で読めなかったため、登録の手順の細部は未確認です

### 楽天ウェブサービス（楽天市場の商品検索）
- 公式：https://webservice.rakuten.co.jp/documentation/ichiba-item-search（版 2026-07-01）
- **アプリ ID とアクセスキーの両方**が必要です
- 回数の数値は書かれていませんが、短い時間に大量に呼ぶと止まります（429）。道具は1回ずつ1秒あけます
- **クレジット表示が必須**（https://webservice.rakuten.co.jp/guide/credit）。結果を人に見せる画面・ページに表示します
- 規約（https://webservice.rakuten.co.jp/guide/rule）の第10条(10)は「特定の人しかアクセスできない環境での利用」を、楽天が許可した場合を除き禁じています。自分だけが使う道具が当たるかどうかは、使う前に規約を読み、分からなければ楽天に問い合わせてください
- 検索するだけです。購入の操作はできません

### Yahoo!ショッピング（商品検索 v3）
- 公式：https://developer.yahoo.co.jp/webapi/shopping/v3/itemsearch.html
- Client ID（appid）が必要。**1秒に1回まで**。超えると 429
- **クレジット表示が必須**（https://developer.yahoo.co.jp/attribution/）
- JAN コードで探せます（jan_code）

### Keepa（任意）
- 有料の API です。料金・利用条件はこのキットを作った時点では公式ページを機械で読めず**未確認**です。契約前に keepa.com で読んでください

### やらないこと（どの売り場・どのサービスでも）
- 画面の自動読み取り（スクレイピング）・ログインした画面の自動操作で情報を大量に取ること
- 自動で大量のフォロー・いいね・メッセージを送ること
- 1つのサービスに、決まりを超える速さで呼び出すこと

## 売り場の決まり（Amazon.co.jp の例）

- **ドロップシッピングの決まり**：仕入れ先から購入者へ直接送らせ、納品書や箱に仕入れ先の名前が入る形は固く禁じられています。一度自分（または契約した発送の会社）が受け取り、仕入れ先の書類を全部抜いてから送ります。購入者の返品も自分が受けます。最新の決まりはセラーセントラルのヘルプ「ドロップシッピングポリシー」で確かめてください（このキットを作った時点では機械で本文を読めず、要点だけを書いています）
- **出品制限**：カテゴリ・ブランド・商品によっては出品に許可が要ります。`sp_api.py seigen` で確かめます
- **指標**：取り消し率・出荷遅延率・注文不良率などに基準があります。基準を超えると出品が止められることがあります
- **知的財産**：権利者からの申し立てを受けると、出品の削除・ブランド全体の停止・アカウントの停止につながることがあります。偽物でなくても、メーカーが値崩れを防ぐ目的で申し立てることがあります

ほかの売り場（フリマ・ほかのモール）を使うときも、同じ観点（API の有無と条件・無在庫の扱い・発送日数・禁止品）で、その売り場の規約を読んでから始めます。読んだ規約の URL と日付を `data/kiyaku-yonda.md`（リポジトリに入らない）に残します。

## 法律（日本で売るとき・概要。最新と詳細は所管の役所の公式で）

| 気をつけること | どんなときに関係するか | 確かめる先 |
|---|---|---|
| 古物営業法 | 法律の言う「古物」（一度使われた物、または使っていなくても使うために一度取引された物）を仕入れて売るとき。小売店で買った新品を売る場合も当たることがある。許可が要る | 住んでいる都道府県の警察（古物商許可） |
| 特定商取引法 | ネットで売るとき。事業者の表示などの決まり | 消費者庁 |
| チケット不正転売禁止法 | 特定の興行のチケットの転売は禁止 | 文化庁 https://www.bunka.go.jp/seisaku/bunka_gyosei/ticket_resale_ban/index.html |
| 酒税法 | お酒を売るとき。免許が要る | 国税庁 |
| 医薬品医療機器等法（薬機法） | 医薬品・医療機器・化粧品など。販売の許可・広告の表現の決まり | 厚生労働省・都道府県 |
| 電気用品安全法 | 電気製品（PSE マークの対象） | 経済産業省 |
| 食品衛生法 | 食品 | 保健所 |
| 景品表示法 | 説明文の言い過ぎ（一番・最安など） | 消費者庁 |

このキットの初期設定では、許可が要るカテゴリ（医薬品・化粧品・食品・お酒・チケットなど）を判定で外しています。許可を取ってから外してください。
