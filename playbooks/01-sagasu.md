# 01 仕入れ候補を探す

目的：「売れている」商品のうち、自分が相乗りして売っても危なくないものだけを残す。
順番が大事です。**売れているかを先に確かめ、仕入れ先は後で探します。** 仕入れ先から探すと「安いけど売れない物」ばかり集まります。

## 手順

1. 候補を集める（どれか1つ）
   - Keepa の製品検索（契約している場合）で、ランキング・出品者数・値段の帯・売り場本体の有無で絞る
   - 売り場の売れ筋ランキングをオーナーが画面で見て、気になる商品の ASIN を書き出す
   - 過去に売れた商品の、同じブランド・同じ分類の別の商品
   - 機械で売り場の画面を大量に読む方法（スクレイピング）は使わない

2. `samples/candidates.csv` と同じ列の CSV を作る（1商品1行）

   | 列 | 意味 | どこで見るか |
   |---|---|---|
   | rank | 売れ筋ランキング | 商品ページ・Keepa |
   | uriage_tsuki | 月に売れる数の見込み | Keepa（無ければ空） |
   | shuppinsha / shuppinsha_30d_mae | 新品の出品者数（今／30日前） | Keepa・SP-API getItemOffers |
   | hontai_cart_90 / _365 | 売り場本体がカートを取った割合（0〜1） | Keepa |
   | jibun_hassou_cart | 自己発送の出品者がカートを取った割合 | Keepa（自己発送で売る人だけ要る） |
   | ima / avg30 / avg90 / avg180 | 今の値段と平均 | Keepa |
   | kakaku_kotei_hi | 値段が動いていない日数 | Keepa のグラフ |
   | kyoka | 出品に許可が要るか（yes / no / unknown） | `sp_api.py seigen` |
   | sell | 送料込みの売値 | 今のカートの値段 |
   | cost | 仕入れ値（割引の後） | `02-rieki.md` |
   | fee_en | 手数料の実額 | `sp_api.py fees` |

   分からない欄は空にします。**空は「安全」ではありません。** 判定は「要確認」になって通りません。

3. 判定する

   ```
   python3 scripts/hantei.py 自分の候補.csv
   ```

4. 「要確認」は、足りない値を調べて埋め、もう一度判定する。「止める」は理由を読み、理由に納得できないときだけオーナーに聞く（勝手に通さない）。

5. 「通す」になった商品だけ、仕入れ先を探す

   ```
   python3 scripts/shiire_sagasu.py --jan JANコード --kataban 型番 --irisu 入り数 --go
   ```

   - JAN が分かるなら JAN で探す（名前で探すと別の品が混ざる）
   - 型番は空白とハイフンを詰めて**完全一致だけ**残す（型番の一部だけ同じ別の品がある）
   - 入り数（1個・3個セット）を必ず突き合わせる。違うと「別の品」の申し立てで負けます
   - 中古・訳あり・箱なし・最低注文額つきは外す
   - **仕入れ先を2つ以上**見つける（1つが品切れでも取り消しにならない）

6. 仕入れ値が決まったら `02-rieki.md` で利益を出し直す

## 避ける商品（判定の初期値に入っているもの）

- 出品者が1〜2人：メーカー自身・独占の販売の恐れ。相乗りすると権利者から申し立てられることがある
- 出品者が急に減った（売れ行きは落ちていない）：権利の申し立てで締め出された跡かもしれない
- 値段がずっと同じ：メーカーが値段を守っていて、安く売る人を申し立てることがある
- 値段が下がり続けている
- 売り場本体がほとんどカートを取っている
- 化粧品・医薬品・食品・お酒など：売り場の許可や法律の許可が要る（`05-kiyaku.md`）
- 壊れやすい・溶ける・重い・大きい：送料と破損で利益が消える
- 高すぎる物：1回の事故（破損・盗難・返品）に耐えられない額は避ける

条件の数字は `config/settings.json` の `hantei` で変えられます。変えたら理由を `templates/houkoku-shuu.md` の形で残します。
