# 06 止まったとき

| 出た表示 | よくある原因 | やること |
|---|---|---|
| 止めます：◯◯ が .env にありません | 鍵が入っていない | README の「必要なキーと取り方」。鍵はオーナーが取って `.env` に入れる |
| HTTP 400 | 送った値の形が違う | 道具の試し運転（--go なし）で送る中身を見て、公式の説明と比べる |
| HTTP 401 / 403 | 鍵が違う・期限切れ・権限が足りない | 鍵を作り直す前にオーナーに知らせる（勝手に作り直さない） |
| HTTP 429 | 呼ぶのが速すぎる | 道具は数回だけ待ってやり直す。続くなら時間をおく。回数を増やさない |
| 判定が全部「要確認」 | 表の列名が違う・値が空 | 1行目の列名を `samples/candidates.csv` と比べる |
| 判定が全部「止める」 | 条件が厳しすぎる、または仕入れ値が高い | 止める理由を数える。条件を変える案はオーナーへ（勝手に緩めない） |
| 仕入れ先が0件 | 型番・入り数の照合で全部外れた | 外した理由（--json の dropped）を読む。照合を外して通さない |
| 売り場から警告・申し立てが届いた | 権利・規約・指標 | 対象の出品をまず止め、止まったことを確かめてから、警告の本文を添えてオーナーへ |

## 決まり

- 直したつもりで先へ進まない。直したら、同じ道具をもう一度動かして結果を確かめる
- お金・売り場に関わることは、手を止めてオーナーに知らせる
- 同じ止まり方が2回あったら、この表に1行足す案を出す
