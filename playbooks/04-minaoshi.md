# 04 在庫と値段の見直し（毎日）

出品中の商品ごとに、仕入れ先の値段と在庫・他の出品者の値段を見て、赤字と取り消しを先に防ぎます。

## 手順

1. `samples/listings.csv` と同じ列で、出品中の商品の表を作る
   - sell：今の売値／cost：今日見た仕入れ値／cost_mae：前回見た仕入れ値
   - shiire_zaiko：仕入れ先の在庫数（API や仕入れ先の表示で確かめる。分からなければ空）
   - saiyasu：他の出品者の最安（送料込み・`sp_api.py offers` で見られる）
   - shiire_2：2つ目の仕入れ先があるか（有／無）
2. 見直す

   ```
   python3 scripts/minaoshi.py 自分の出品.csv
   ```

3. 案の強い順に処理する

| 案 | やること | 誰が決める |
|---|---|---|
| 止める | 在庫を0にして出品を止める（`sp_api.py teishi`） | 自動にしてよいとオーナーが決めた後はエージェント。それまではオーナー |
| 上げる | 下限まで値段を上げる（`sp_api.py nedan`） | 同上 |
| 合わせる | 最安に寄せる（下限より下げない） | 同上 |
| 要確認 | 足りない値を調べる | エージェント |

売り場を変える操作は、最初は必ず `--preview`（検証だけ）で通し、返事に問題がないことを確かめてから本番にします。

## なぜ毎日か

- 売れてから仕入れる形では、仕入れ先の品切れ＝**注文の取り消し**です。取り消しは売り場の評価（取り消し率）に直結し、続くと出品が止められます
- 注文が少ない始めの時期ほど、1件の取り消しの重みが大きくなります
- だから「品切れになってから」ではなく「在庫が少なくなった時点」で止めます

## 売り場の評価を守る設定（Amazon の例・最新は公式ヘルプで確かめる）

- 出荷までの日数を、実際にできる日数に設定する
- 1日に受ける注文数に上限を掛けられる設定があれば使う（始めのうちは少なく）
- 指標（取り消し率・出荷遅延・注文不良率）を毎週見て、悪くなったらオーナーに知らせる
